Help — Home

Welcome to the Workplace Safety Training Certification Database help system.

The Home page displays the latest news and announcements from the system administrator. News items are shown in reverse chronological order, with the most recent items appearing first.

Navigation

Use the menu bar at the top of the page to navigate between different sections of the application. Each menu item contains a dropdown with available options. The menus available to you depend on your assigned role:

  • Superuser — Full access to all features including User Management and News Management.
  • Data entry — Can add, edit and delete persons, certifications, and facilities. Cannot manage users.
  • Read only — Can view records only. Cannot add, edit or delete any data.

Using the System

To get started, select the appropriate section from the navigation menu. For example, to view all registered people, go to Person > View people. To add a new certification record, go to Certification > Add certification.

Data Entry Guidelines

When entering data, fields marked with a red asterisk (*) are mandatory. Ensure all required fields are completed before submitting. The system will display validation messages in red if any required information is missing.
