# Defra Legacy Reverse Engineering Plugin

This system assists engineers working on understanding and re-engineering legacy systems.

## Context

This project will take inputs from legacy software systems including, source code, tests, screenshots, SME interviews, telemetry and logs etc, it will produce a PRD and a set of features for re-engineering

## Conventions

- Use American English in all generated documentation
- Refer to the programme as "LAP" or "Legacy Application Programme"
- Treat all legacy code as potentially undocumented — never assume documentation exists
- When creating a new skill, add an entry to the Skills table in README.md
- When creating a new agent, add an entry to the Agents table in README.md
